# NOVA Studio — Modern Digital Agency Website

This project is an industrial training frontend interface created for **NOVA Studio**, implementing a responsive multi-page website matching the design system specifications.

## Technologies Used
* **HTML5** (Semantic layout structure)
* **CSS3** (Custom Design System, Flexbox, CSS Grid, Media Queries)
* **Vanilla JavaScript** (Mobile navigation toggle, dynamic project filtering, client-side contact form validation)

## Setup & Running Locally
1. Download or clone this directory repository structure locally.
2. Open `index.html` directly in any standard web browser (Chrome, Firefox, Edge, Safari). No build tool or server setup is required.
